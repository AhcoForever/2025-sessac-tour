## 🎯 프로젝트 소개

**SOFE BEAT**는 서울시 365 챌린지를 AI 기반으로 확장한 차세대 공공여가 서비스입니다.

AI 캐릭터와 대화하며 오늘의 활동을 추천받고, 이동 중 수집된 **환경음·걸음 리듬·사진·감정**을 하나의 음악으로 생성하여 **나만의 서울 사운드트랙**을 만들 수 있습니다.

### 💡 핵심 가치

- 🤖 **AI 캐릭터 대화형 추천**: 감정·날씨·위치·시간 기반 개인화된 여가 활동 추천
- 🎵 **음악 기반 창작 인증**: 사진 대신 음악으로 하루를 기록하는 새로운 인증 방식
- 🗺️ **GPS 정서적 동행**: 이동 경로 안내 + 관찰 포인트 제시로 외출 부담 감소
- 🔒 **프라이버시 보호**: 얼굴 노출 없이 감정과 경험을 공유

### 🎨 서비스 특징

**SOFE BEAT**은 기존 365 서울챌린지의 세 가지 핵심 Pain Point를 AI 기술로 해결합니다:

1. **활동 선택의 부담** → AI 기반 개인 맞춤형 추천으로 해결
2. **혼자 외출할 때의 심리적 장벽** → AI 캐릭터 동행 기능으로 해결
3. **기록·인증 방식의 한계** → 음악 생성 기반 자동 인증으로 해결

## 📌 제안 배경 및 목적

### 1. 365 서울챌린지의 성과와 확장 필요성

365 서울챌린지는 시민이 일상에서 외출과 기록을 가볍게 시작하도록 돕는 데 성공한 정책입니다:
- 1기 모집 5일 만에 목표 인원(5,000명)을 초과해 7,500명 마감
- 하루 평균 321명의 인증 제출
- 무기력 완화, 활동 반경 확대 등 긍정적 시민 피드백 다수

이러한 성과는 더 많은 시민 참여를 수용하고 참여 과정의 질을 높이기 위한 **확장 단계**에 다다랐음을 의미합니다.

### 2. AI를 활용한 해결책

**SOFE BEAT**은 다음 세 가지 AI 기술로 확장 요구사항을 해결합니다:

#### ① AI 기반 개인화 추천
- 공공여가 데이터와 개인의 감정·시간·거리·컨디션을 결합
- "오늘 가능한 활동" 자동 추천으로 선택 피로도 감소

#### ② AI 캐릭터와 정서적 동행
- 길 안내, 관찰 포인트, 가벼운 감정 질문
- 혼자 외출 시 느끼는 심리적 장벽 완화
- 계획과 실제 행동 사이의 간극을 줄여 실행률 향상

#### ③ 음악 기반 창작 및 기록 인증
- 환경음·걸음 리듬·사진·메모·감정을 하나의 음악으로 재구성
- 얼굴 노출 부담 없이 개인의 감정·환경·상황을 자연스럽게 담아냄
- 기록이 단순 인증을 넘어 "하루가 하나의 작품"으로 남는 경험 제공
- 자동 인증으로 운영 부담 감소

## 🚀 핵심 기능

### 1. 캐릭터 기반 AI 대화형 여가 추천

<img src="docs/screenshots/character_select_page.gif" width="300">
<img src="docs/screenshots/chat-path.gif" width="300">

- **3가지 AI 캐릭터**: 소울해치, 댕댕청룡, 돌격백호 중 선택
- **대화형 상황 파악**: 실시간 대화로 감정·시간·거리·컨디션 파악
- **맞춤형 추천**: 서울시 공공데이터 기반 오늘 가능한 활동 3개 제안
- **추천 알고리즘**: LLM + Rule-based hybrid 모델 활용

**대화 예시**:
```
AI: "오늘 기분은 어때?"
AI: "얼마나 걸을 수 있어?"
AI: "집 근처/조금 멀리, 뭐가 좋아?"
AI: "조용한 곳/활기찬 곳 중 뭐가 끌려?"

→ 대화 후 오늘 가능한 챌린지 3개 자동 제안
   (카드형: 이미지·거리·예상시간·분위기 태그 포함)
```

### 2. GPS 기반 실시간 동행 기능

- **실시간 이동 트래킹**: 카카오 맵 + Google Maps 활용
- **경로 안내**: Kakao Mobility Directions API로 도보 경로 안내
- **캐릭터 길 안내**: 친근한 음성/텍스트 가이드
- **상황 반응 메시지**: 위치와 환경에 따른 동적 반응
- **관찰 포인트 안내**: 특별한 장소에서 관찰 미션 제시
- **사진 촬영**: 경로 중 추억을 사진으로 기록

### 3. 사진 기반 추억 기록 (현재 구현)

**현재 구현된 기능**:
- 이동 중 카메라로 사진 촬영
- 촬영한 사진 갤러리에서 확인
- Firebase Storage에 사진 저장
- 위치 정보와 함께 사진 메타데이터 저장

**향후 음악 생성 기능 (개발 예정)**:
1. 수집 데이터 확장: 환경음, 걸음 리듬, 감정 메모, 음성 메모
2. 생성형 AI(MusicGen, Riffusion 등)로 음악 파일 생성
3. 사용자가 장르 선택 가능 (차분한/활기찬/감성적 등)
4. "오늘의 음악" 자동 생성 및 재생
5. 생성된 음악을 챌린지 인증으로 자동 제출
6. 사운드 포스트(커뮤니티)에 음악 공유

### 4. 사용자 프로필 및 활동 기록

- **프로필 관리**: 사용자 정보 및 설정 관리
- **활동 기록**: 완료한 챌린지 목록 확인
- **사진 보관함**: 촬영한 사진들을 날짜별로 정리
- **통계**: 이동 거리, 참여 횟수 등 활동 통계

### 5. 향후 계획: 사운드 포스트 커뮤니티 (개발 예정)

- **음악 피드**: 시민들이 만든 음악을 감상
- **자동 태그**: 감정 태그, 장소 태그 기반 분류
- **상호작용**: 공감, 댓글, "이 챌린지 참여하기" 연결
- **서울 음악 지도**: 서울을 "음악으로 경험하는 지도" 형태로 축적

## 🛠 기술 스택

### Frontend
- **Flutter 3.35.2**: 크로스 플랫폼 모바일 앱 개발
- **Dart 3.9**: Flutter 기반 언어

### Backend & Database
- **Firebase**:
  - Authentication: 이메일/비밀번호 인증
  - Firestore: NoSQL 실시간 데이터베이스
  - Cloud Functions: 서버리스 백엔드 로직
  - Storage: 사진 및 사용자 데이터 저장

### AI & Machine Learning
- **Claude Haiku 4 (Anthropic)**:
  - 대화형 AI 챗봇
  - 개인화 추천 알고리즘
  - 정서 분석 및 동행 반응 생성
- **LLM + Rule-based Hybrid**: 추천 모델 최적화
- **향후 계획: 생성형 AI 음악 모델**:
  - MusicGen: Meta의 오픈소스 음악 생성 모델
  - Riffusion: 텍스트-음악 변환
  - 공유마당 음원 데이터 기반 학습

### Maps & Location
- **카카오 맵 (Kakao Map Plugin)**: 지도 표시 및 마커 관리
- **Google Maps Flutter**: 지도 UI 및 인터랙션
- **Kakao Mobility Directions API**: 도보 경로 안내
- **Geolocator**: 실시간 GPS 위치 추적

### External APIs
- **서울 열린데이터광장 API**:
  - 문화행사정보
  - 야경명소정보
  - 서울시 문화공간 정보
- **서울관광재단 VisitSeoul API**: 관광/문화행사 정보
- **기상청 중기예보 조회서비스**: 날씨 기반 추천

### Development Tools
- **Git & GitHub**: 버전 관리 및 협업
- **Figma**: UI/UX 디자인

```
│              │ │              │ │ • 기상청     │
│ • 대화 생성  │ │ • MusicGen   │ │ • 카카오맵   │
│ • 추천 로직  │ │ • Riffusion  │ │ • Google Maps│
│ • 정서 분석  │ │              │ │              │
└──────────────┘ └──────────────┘ └──────────────┘
```

**서비스 흐름**:
1. 사용자가 AI 캐릭터와 대화 → Claude API로 감정·상황 분석
2. 서울시 공공데이터 + 사용자 상태 → AI 추천 엔진에서 활동 3개 제안
3. 활동 선택 후 GPS 트래킹 시작 → 카카오 맵/Google Maps + 캐릭터 동행
4. 이동 중 사진 촬영 및 데이터 수집 → Firebase Storage 저장
5. 도착 후 활동 완료 인증 → Firestore에 기록
6. **(향후 계획)** 음악 생성 요청 → 생성형 AI가 음악 파일 생성
7. **(향후 계획)** 사운드 포스트 공유 → 커뮤니티에서 시민 간 경험 공유

## 💰 기대 효과

### 1. 공공여가 서비스의 확장성과 지속가능성 확보 (정책적 효과)

- **운영 효율화**: 사진·문자 검수 → 음악 기반 자동 인증으로 전환, 검수 인력·운영 비용 대폭 감소
- **확장성 확보**: 활동 기획·추천 → AI 자동 생성으로 챌린지가 늘어나도 행정 부담 증가 없음
- **참여 흐름 고도화**: '외출–기록–보상' → '외출–동행–창작–보상·공유'로 진화
- **재참여율 증가**: 시민 참여 동기와 재참여율 대폭 향상

### 2. 멀티모달·생성형 AI 실증 (기술적·경제적 가치)

**정책 분야 최초의 멀티모달 AI 서비스**:
- GPS, 환경음, 텍스트, 이미지, 감정 정보 통합 처리
- 추천–동행–음악 생성까지 수행하는 End-to-End AI 파이프라인

**기술적 자산 확보**:
- 공공여가 데이터 정제·추천 AI 파이프라인
- 실시간 이동·정서·환경 해석 멀티모달 엔진
- 생성형 AI(음악 생성)의 공공 서비스 적용 사례
- 시민 참여형 데이터 수집·AI 활용 모델

→ 향후 교통·안전·복지·문화 등 다양한 분야로 확장 가능한 **레퍼런스 모델** 제공

### 3. 서울 고유의 '정서·경험 데이터' 축적 (도시 자산화)

**새로운 유형의 도시 데이터**:
- 장소 × 감정 태그
- 시간대별 시민 정서 변화 패턴
- 걸음 리듬·환경음·기상 등 이동 기반 신호
- 일상 경험이 반영된 음악 메타데이터

**활용 가능성**:
- 도시 정서 지도 구축
- 문화·관광·정서 건강 정책 고도화
- 서울형 소버린 AI 개발
- 장기적 가치가 높은 **새로운 도시 AI 자산** 확보

### 4. 시민 창작 활동 촉진 (창작경제 효과)

- **얼굴 노출 없는 음악 기반 인증**: 프라이버시 보호 + 참여 장벽 감소
- **1클릭 SNS 공유**: 유튜브, 틱톡, 릴스 자동 업로드
- **저작권 해결**: 공유마당 기반 국내 데이터로 학습
- **창작 생태계 선순환**: 시민 음악 → AI 학습 → 고도화된 생성 모델 → 다시 시민에게 제공

### 5. 외출 증가·재방문 유도 (직접·간접 경제효과)

**지역경제 활성화**:
- 지역 행사·문화시설·체육시설 이용 증가
- 지역 상권 방문 확대
- 서울페이 기반 소비 촉진
- 음악 기반 장소 브랜딩 → 애착 형성 및 재방문율 증가

**사회적 비용 절감**:
- 정서 회복 → 우울감·고립감 감소
- 장기적 사회적 비용 절감

→ **시민이 걷는 만큼, 참여하는 만큼, 지역이 살아나는 구조**

## 💻 설치 및 실행

### 필수 요구사항
- Flutter SDK 3.35.2 이상
- Dart 3.9 이상
- Android Studio / Xcode (모바일 빌드용)
- Firebase CLI

### 설치 방법

1. **레포지토리 클론**
```bash
git clone https://github.com/AhcoForever/2025-sessac-tour.git
cd 2025-sessac-tour
```

2. **의존성 설치**
```bash
flutter pub get
```

3. **Firebase 설정**
```bash
# Firebase 프로젝트 설정 파일 필요
# firebase_options.dart 파일 생성 또는 제공받기
```

4. **환경 변수 설정**
```bash
# .env 파일 생성 및 API 키 설정
CLAUDE_API_KEY=your_claude_api_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

5. **실행**
```bash
# Android
flutter run -d android

# iOS
flutter run -d ios

# 웹 (개발 모드)
flutter run -d chrome
```

### 빌드

```bash
# Android APK
flutter build apk --release

# iOS
flutter build ios --release

# 웹
flutter build web
```
