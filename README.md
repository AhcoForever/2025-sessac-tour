## 프로젝트 소개
**SOFE**는 서울시 365 챌린지를 AI 기반으로 확장한 차세대 공공여가 서비스입니다.  
AI 캐릭터와 대화하며 오늘의 활동을 추천받고, 이동 중 수집된 환경음·걸음 리듬·사진·감정을
하나의 음악으로 생성하여 나만의 서울 사운드트랙을 만들 수 있습니다.


###  핵심 가치
- 🤖 **AI 캐릭터 대화형 추천**: 감정·날씨·위치 기반 개인화
- 🎵 **음악 기반 창작 인증**: 사진 대신 음악으로 하루 기록
- 🗺️ **GPS 정서적 동행**: 이동 경로 안내 + 관찰 포인트 제시
- 🔒 **프라이버시 보호**: 얼굴 노출 없이 감정 공유
